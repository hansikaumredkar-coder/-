# 3rd Month Anniversary Website

Open `index.html` in a browser to preview it.

To put it online:
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. In GitHub go to Settings -> Pages.
4. Choose "Deploy from a branch", select `main` and `/root`.
5. Save and wait for the website link.

Easy edits:
- Change nicknames in index.html.
- Change the paragraphs in index.html.
- Replace photos inside `assets` while keeping the same filenames.
